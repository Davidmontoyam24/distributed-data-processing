# distributed-data-processing
Proyecto académico de procesamiento y análisis de datos utilizando Python y Apache Spark.
# PySpark Data Engineering Project
# Tecnologías utilizadas
- Python
- Apache Spark
- PySpark
- Spark SQL

# Objetivo
El objetivo del proyecto es procesar, transformar y analizar conjuntos de datos utilizando herramientas de procesamiento distribuido.

# Funcionalidades
- Carga de datos
- Limpieza y transformación de información
- Consultas utilizando Spark SQL
- Procesamiento de datos con PySpark
- Análisis de resultados
